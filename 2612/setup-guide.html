Laptop setup guide

Please install the following programs on your laptop before the course:

  • a program to log in to the cluster and copy files (Windows only, see below)
  • ChimeraX 1.12 with the ArtiaX plugin
  • 3dmod, the viewer from IMOD

You need a laptop on which you can install software. Choose your operating system below.

Problems with the installation?

Contact Gerrit Timpert at gerrit.timpert@scilifelab.se. If needed, we can also solve it together in a short Zoom call before the course.

  • Windows
  • macOS
  • Linux (Ubuntu)

1. MobaXterm (cluster login and files)

MobaXterm logs in to the cluster and shows the cluster’s files in a sidebar, where you can download them. The free Home Edition is enough.

  1. Open the MobaXterm download page and click Download now under Home Edition.

  2. Click Installer edition.

  3. Unzip the downloaded file and run the installer in it with the default settings.

  4. Start MobaXterm and click Session.

  5. Click SSH.

  6. Enter login.cryoem.se as Remote host and your course user name as Username. Click OK.

  7. The first time you connect, MobaXterm asks whether you trust the server. Click Accept.

  8. Type your password and press Enter. The password is not shown while you type.

  9. After the login, the sidebar on the left shows your files on the cluster. To copy a file to your laptop, right-click it and choose Download.

MobaXterm saves the session in the sidebar. Next time, double-click it to log in again.

2. ChimeraX 1.12 with ArtiaX

  1. Open the ChimeraX download page. Under the heading ChimeraX 1.12, click ChimeraX-1.12.exe. Do not take the release candidate or the daily build at the top of the page: ArtiaX does not work with them.

  2. Run the installer with the default settings.

  3. Start ChimeraX. Click into the field next to Command: at the bottom of the window, type toolshed install ArtiaX and press Enter. The log shows “Installed ChimeraX-ArtiaX”. If orange warnings about numpy appear above it, you can ignore them.

  4. In the same field, type pip install pandas==3.0.5 and press Enter. The log shows no message for this command. That is normal.

    Why this step?

    The current ArtiaX release installs a pandas version that does not work with ChimeraX 1.12, so ArtiaX does not start. This step installs a version that works.

  5. Quit ChimeraX (File, Quit) and start it again.

  6. Click the ArtiaX tab at the top, then Launch.

  7. The ArtiaX panel opens. ChimeraX and ArtiaX are ready.

3. 3dmod

Already have IMOD?

If the full IMOD is already installed on your laptop, the standalone 3dmod does not start. Use the 3dmod from your IMOD installation and skip this part.

On Windows you only need 3dmod, not the full IMOD. 3dmod is available as a standalone package.

  1. Open the 3dmod download folder and click 3dmodForWin64-5.2.7.exe.

  2. Double-click the downloaded file. Keep the destination folder C:\Program Files and click Extract.

    If Windows shows a blue warning, click More info and then Run anyway. If Windows asks for administrator rights, right-click the file and choose Run as administrator.

  3. Open the folder C:\Program Files\3dmod.

  4. Right-click 3dmod and choose Send to, Desktop (create shortcut). On Windows 11, you may first have to click Show more options.

  5. Start 3dmod from the desktop shortcut. In the window “3dmod Startup”, click Select… next to Image file(s), choose a file and click OK.

  6. To test it, download golgi.mrc and open it. 3dmod shows the image, and its info window shows “3dmod 5.2.7”.

The screenshots show a Mac with Apple Silicon (M1, M2, …).

1. Cluster login and files

Nothing to install. Open the app Terminal (in Applications, Utilities).

  1. To log in, type the following and press Enter. Use your course user name instead of <user>.

    ssh <user>@login.cryoem.se

  2. The first time you connect, the Terminal asks whether you want to continue connecting. Type yes and press Enter. Then type your password and press Enter. The password is not shown while you type. After the login, the prompt shows your user name and login1.

  3. To log out, type exit. To copy a file from the cluster to your laptop, use scp in a Terminal on your laptop (not on the cluster):

    scp <user>@login.cryoem.se:<path on the cluster> ~/Downloads/

2. IMOD (3dmod)

IMOD needs Python on the Mac.

  1. In the Terminal, type python3 --version and press Enter. If it shows a version number, Python is installed and you can go on with step 2.

    If it shows an error or asks to install developer tools, install Python first: the IMOD download page links the Python 3.10 installer from python.org in its Mac section.

  2. Open the IMOD download page and go to Latest Stable Release Packages - Mac. For a Mac with Apple Silicon, click clickable installer in the line Mac OS 12 - 27 for arm64 processor. For an Intel Mac, use the line for Intel processor.

  3. Double-click the downloaded .pkg file and follow the installer with the default settings. It asks for your Mac password.

  4. Close the Terminal and open a new one. The new Terminal knows where IMOD is. Type which 3dmod: it shows /Applications/IMOD/bin/3dmod.

  5. Type 3dmod and press Enter. In the window “3dmod Startup”, click Select… next to Image file(s), choose a file and click OK. Do not use the 3dmod icon in Launchpad: it does not work.

  6. To test it, download golgi.mrc and open it. 3dmod shows the image.

3. ChimeraX 1.12 with ArtiaX

  1. Open the ChimeraX download page. Under the heading ChimeraX 1.12, click ChimeraX-1.12.dmg. For an Intel Mac, click Other platforms below it. Do not take the release candidate or the daily build: ArtiaX does not work with them.

  2. Open the .dmg file and drag ChimeraX-1.12 to Applications.

  3. Start ChimeraX from Applications. The first start shows a registration form. You can fill it in or close it.

  4. Click into the field next to Command: at the bottom of the window, type toolshed install ArtiaX and press Enter. The log shows “Installed ChimeraX-ArtiaX”. Orange warnings about numpy above it are normal and can be ignored.

  5. In the same field, type pip install pandas==3.0.5 and press Enter. The log shows no message for this command. That is normal.

    Why this step?

    The current ArtiaX release installs a pandas version that does not work with ChimeraX 1.12, so ArtiaX does not start. This step installs a version that works.

  6. Quit ChimeraX (ChimeraX, Quit ChimeraX) and start it again.

  7. Click the ArtiaX tab at the top, then Launch.

  8. The ArtiaX panel opens. ChimeraX and ArtiaX are ready.

These instructions are for Ubuntu 22.04 and 24.04.

1. Cluster login and files

Nothing to install. In a terminal, use ssh to log in and scp to copy files:

ssh <user>@login.cryoem.se
scp <user>@login.cryoem.se:<path on the cluster> .

2. ChimeraX 1.12 with ArtiaX

  1. Open the ChimeraX download page. Under the heading ChimeraX 1.12, click Other platforms and download ucsf-chimerax_1.12ubuntu24.04_amd64.deb (Ubuntu 24.04) or ucsf-chimerax_1.12ubuntu22.04_amd64.deb (Ubuntu 22.04).

  2. Install it, for example on Ubuntu 24.04:

    sudo apt install ~/Downloads/ucsf-chimerax_1.12ubuntu24.04_amd64.deb

  3. Start ChimeraX with the command chimerax.

  4. Follow steps 3 to 7 of the Windows instructions: toolshed install ArtiaX, then pip install pandas==3.0.5, restart ChimeraX, then ArtiaX, Launch.

3. IMOD (3dmod)

  1. Open the IMOD download page and download the package under Red Hat Enterprise Linux 8 - CUDA 12 (imod_5.1.13_RHEL8-64_CUDA12.0.sh). Despite its name, this is the package the IMOD team recommends for Ubuntu 20 and newer.

  2. Install it from a terminal in the download folder:

    sudo sh imod_5.1.13_RHEL8-64_CUDA12.0.sh

  3. Log out and log in again, then open a terminal and type 3dmod. See the Windows instructions, step 5, for how to open a file.
